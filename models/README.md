
# OralSense AI — Trained Models

This directory documents the trained model files
required by the Streamlit application.

Required files:

1. ConvNeXtTiny_best.pth
2. DINOv2SVM_best.joblib
3. OralSense_Adaptive_Policy.joblib
4. dinov2_vits14_pretrain.pth

The DINOv2 source code is also required.

Model weights are not committed directly to GitHub.

Model download and setup instructions will be
added after selecting a model hosting service.
